預備篇：學前指引與課程目標 (第 0 章)

精神指引
  1. 課程核心精神： 學習不是為了考試，而是為了找到適合自己的生活方式。課程鼓勵大家從「被動接收者」轉變為「主動的實踐者（Doer）」。
  2. 揚棄傳統管理思維： 面對人生 100 年，不要再用講求完美的 PDCA (計畫-執行-考核-行動) 來逼迫自己，這會帶來極大的焦慮。
  3. 推崇 AAR 生活實驗： 改用 AAR (Anticipation預期 ➔ Action行動 ➔ Reflection反思)。抱著玩心與期待去嘗試，在行動中反思，從做中學。
  4. 學習的五大節奏： 每章皆依循「觀念對談 ➔ 他山之石 ➔ 大師開講 ➔ 在地連結 ➔ 重點迴盪」的節奏進行。

第一章：社會轉型與學習觀的變遷

核心觀念
  1. 價值觀的轉型與焦慮：
    • 從單一走向多樣： 過去工業社會是一條「單一穩定的路」（好學校➔好公司➔退休），用金錢與物質衡量幸福。如今選擇變多，價值觀多樣化，反而讓人產生「跟不上社會」的焦慮與不安。
    • 從「佔有」到「存在」： 社會從追求物質的「佔有慾望社會」，轉向追求在人際中被認可的「存在慾望社會」。
  2. 決定幸福感的三大要素 (主觀幸福感)： 過去擇偶看「三高」。現在決定幸福的前三名：1. 身體健康、2. 良好的人際關係、3. 自我決定。
  3. 伊斯特林悖論 (Easterlin Paradox)： 經濟發展到一定水準後，人們的滿足感與幸福感反而會停滯或下降。因為追求更多金錢需要付出更大心力，反而被金錢束縛。
  4. 學校制度的起源與侷限：
    • 為工業社會服務： 為了培養「思想統一、動作一致」的標準化勞動力。
    • 圓形監獄 (Panopticon)： 監控思想的設計，採取「灌輸式、集體主義」教學。
  5. 兩種危機與學習的再定義： 學習不再只是為了「獲取知識與技術來工作」，而是為了「創造新的人際連結、互相幫助的關係」。
  6. 從學歷社會邁向「學習型社會」： OECD 提倡「回流教育 (Recurrent Education)」。日本 2006 年修訂《教育基本法》保障終身學習。
  7. 少子高齡化： 從「多生多死」到「少生少死」，少子高齡化是人類能安心長壽的禮物。
  8. 國內外實踐案例：
    • 日本岡媽媽之 TOMO： 「稍微打開一點點」，空屋變社區客廳與沙坑，晚間成國中生安全防護網。
    • 台中審計新村： 將「圍牆打開」，荒廢宿舍成青年創業聚落，沒有圍牆的無齡學校。

第二章：百年人生與學習的轉機

人生設計
  1. 百年人生的挑戰與英雄劇本的終結： 過去的「英雄之旅」劇本已不適用。現代人生是持續不斷的動態故事，可以轉彎、重來。
  2. 人口結構的變遷： 戰前金字塔（多生多死），現在轉變為柱狀的「棺材形狀」（少生多死，活到自然壽命的高齡者）。
  3. 打破對老化的迷思：
    • 流體智力： 記憶力、反應速度，隨年齡下降。
    • 晶體智力： 解決問題、人際溝通能力，會隨著年齡增長而持續上升（薑是老的辣）。老化速度是多樣化且個別化的。
  4. 成為彼此的「故鄉」與老年期超越： 故鄉是人與人的包容關係。長輩在關懷下一代中離開利害關係，發揮人類本質，獲得極高的自我肯定 (Gerotranscendence)。
  5. 國內外實踐案例：
    • 日本小雞蛋計畫 (Tamago)： 有閒長輩主動照顧社區缺乏陪伴的孩子（他人的孫子女）。長輩獲得生命價值，孩子得到溫暖。
    • 台中南區公所「藝文牆」： 四樓牆面成微型藝廊，展出長青學院長輩工藝，給予極大「出場」機會與成就感。

第三章：學校制度的侷限與非正式學習空間

空間重塑
  1. 學校制度的本質與侷限： 工業時代產物，過度強調競爭，剝奪個體多樣性，將人視為均質的存在。
  2. 社會教育的核心功能（甜甜圈理論）： 社會福利像甜甜圈的空洞。「學習」就是貫穿空洞的核心。居民應擺脫「消費者心態」，政府則是「陪跑教練」。
  3. 非正式學習的價值： 廟口泡茶看似無目標，其實是建立信任連結的「社會教室」。
  4. 國內外實踐案例：
    • 島根縣益田市「對話場 (Katariba)」： 大人不說教，分享真實失敗人生。引發連鎖效應，高中生也主動分享生命故事給國中生。
    • 國中生自辦「竹燈會」： 疫情間為撫慰長輩，國中生主動提案辦燈會，展現自治精神。
    • 台中南和里剪紙： 打破教與學界線，樂齡教師與長輩互相陪伴肯定。

第四章：終身學習的政策脈絡與制度建構

制度發展
  1. 終身學習的起源： 保羅·朗格蘭提出。傑羅皮提倡「自我決定的學習權利」。學習是為掌握生活「主導權」。
  2. 回流教育與有薪教育假： 學習像「撒胡椒」均勻分佈各階段，政府需保障有薪教育假，讓員工敢中途下車學習。
  3. 地方創生與自尊心的恢復： 過去農民被迫賭博或打工。豐田市引入都市青年向長輩學習農業，長輩重拾「自豪感」。
  4. 社會處方箋： 靜岡調查發現，運動加「社會參與」能使死亡率降一半。跟家人同住卻「孤食」的男性死亡風險達 1.5 倍。
  5. 國內外實踐案例：
    • 台中南區長青學院 (官學民合作)： 區公所出場地，空大出師資，長輩穿學士袍圓夢落淚。

第五章：終身學習的實踐（AAR與自我實驗）

行動實踐
  1. 重新定義學習與失敗： 過去沒考 100 分叫失敗。現在學習是「做實驗」，試了不適合就換方向，這不叫失敗。
  2. 「學習即生活」： 跟早餐店阿姨閒聊是學習。家庭共學打破權威，建立平等圓桌對話。
  3. AAR 生活實驗法：
    • Anticipation： 帶著好奇心期待。
    • Action： 無壓力嘗試。
    • Reflection： 反思檢視，像颱風般捲入熱情。
  4. 社會的動態拼圖模式： 每個人都有凹凸面（優缺點），尋找互補夥伴，形成動態拼圖。
  5. 國內外實踐案例（開放性共同體）：
    • 日本豐田市「自給家族」： 都市青年「預付買米」分攤風險，假日去種田被當孫子疼，從交易合夥人昇華為「第二故鄉的家人」。
    • 台中「審計新村」： 不依賴完美 PDCA，先推產品 (Action) 再彈性調整 (Reflection)。

第六章：學習即存在的倫理實踐與生命統整

終極大成
  1. 打破標準化： 拒絕工業社會的刻板標籤，在動態拼圖中找到「剛剛好」的歸屬感（入坑）。
  2. 從報恩到「恩送」(Pay it forward)： 將善意無條件傳遞給周遭或下一代，成為創造價值的行動者 (Doer)。
  3. 軟著陸與心理故鄉： 退休高管活躍老化後，85歲易面臨孤獨。必須提前準備「軟著陸」，讓自己成為下一代的「心理故鄉」。
  4. 關懷下一代與老年期超越： 關懷下一代能讓人脫離世俗算計，進入「深邃的宇宙」，平靜迎接最後時光。
  5. 國內外實踐案例：
    • 日本國中生當「社區理事長」： 打破年齡階級，長輩互相尊重聽從指揮，展現完美跨世代平權。
    • 沖繩「攤販式公民館」： 在公園擺傘，公務員「什麼都不做」留白，反激發居民搶當輪值館長，小孩主動幫忙。
    • 台中彩虹眷村： 爺爺畫筆拯救廢墟，彩虹超人吉他注入靈魂。證明「只要有深厚情感，哪裡都能成新故鄉」。
